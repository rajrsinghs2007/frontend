Frequently Asked Questions

Quick answers about the AUCTION marketplace.

Open an active auction, enter an amount at least the current bid plus the minimum increment, and submit.
Placed bids cannot currently be cancelled after submission.
After an auction ends, the highest bidder can create an order from the checkout flow. Payment processing requires a configured payment provider.
Use Sell an Item, complete the listing form and publish the auction listing.
A real platform should verify identity and seller information server-side.
The server processes bids inside a database transaction, and each accepted bid receives a server-side creation timestamp.
JavaScript updates the displayed time every second using the auction end timestamp.
The current checkout creates an order record only. Connect a payment provider such as Razorpay or Stripe before accepting real payments.
Shipping terms are shown on the listing and should be enforced by the production order system.
Reporting is not currently enabled; a moderation/reporting endpoint can be added when required.
